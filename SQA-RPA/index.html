SQA-RPA With Artificial Intelligence Bootcamp

Kurikulum bootcamp Software Quality Assurance & Robotic Process Automation, dikembangkan dari silabus resmi 2026 — dengan integrasi AI (coding assistant, self-healing locator, generative test scenario, IDP, AI-driven analytics) di setiap modul, bukan sebagai topik tempelan.

Java Selenium WebDriver Page Object Model Page Factory Cucumber BDD JUnit 5 UiPath n8n

Apa Isinya

Materi lengkap 6 modul resmi (mengikuti tabel jam & topik silabus asli) plus 1 modul bonus, tiap topik dilengkapi kode contoh dan bagian “AI Corner” di titik-titik integrasi AI yang ditandai di silabus.

Demo Project

Selenium + Cucumber BDD Framework terverifikasi

Java + Selenium + Page Object + Page Factory + Cucumber BDD + JUnit 5 + Extent Report, menguji saucedemo.com. mvn clean test dijalankan bersih 3x berturut-turut — 28/28 test pass.

n8n AI Test Report Workflow terverifikasi end-to-end

Workflow n8n yang menerima laporan JSON Cucumber lewat webhook dan meringkas hasilnya (rule-based, dengan node AI opsional). Diuji dengan request HTTP sungguhan — bukan simulasi.

UiPath RPA Starter starter template

Struktur project + workflow .xaml untuk web scraping & automasi Excel. Belum bisa diverifikasi jalan penuh di environment pembuatannya — ditandai jelas di dokumentasinya sendiri.

Source lengkap (materi Markdown, situs HTML per-modul, dan ketiga demo project) dikembangkan sebagai project standalone, disimpan terpisah dari repo portfolio ini. Halaman ini adalah ringkasannya.
